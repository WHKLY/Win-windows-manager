# 阶段与测试验收

每次验收必须记录日期、环境、操作步骤、预期结果、实际结果和证据。状态只使用 `Passed`、`Failed` 或 `Not tested`。

| A 基础运行、识别与 DryRun | Not started | 等待用户授权开始构建 |
| B 单窗口放置与基础几何 | Not started | 依赖阶段 A |
| C 自动联合优化 | Not started | 依赖阶段 B |

G0 的 `Passed` 仅代表规划与仓库初始化完成，不代表任何产品功能已实现或可用。
