# Windows 手动测试计划

## 目的

在真实桌面和常用应用组合上完成原始规范中的 T01-T26。每项必须记录日期、Windows 版本、DPI、显示器布局、应用版本、操作步骤、实际结果和证据。

状态只允许：

- `Passed`
- `Failed`
- `Not tested`

## 准备

1. 将 `Win-windows-manager-v0.1.1.exe` 与 `config.ini` 放入同一目录。
2. 先保留默认配置并启用 DebugLogging。
3. 打开 Windows Terminal、文件资源管理器、浏览器和 VS Code。
4. 记录启动前窗口几何；测试过程不要同时运行其他窗口管理器。
5. 每类测试结束后检查 `logs/win-windows-manager.log` 是否有未处理异常。
